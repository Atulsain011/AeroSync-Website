Capabilities

Built for the whole file, not a compressed copy of it

100+ MB/s throughput

Zero-copy buffer streaming moves 4K video, ISOs, and full game folders in seconds instead of minutes.

Zero-config discovery

UDP beacon broadcasts and mDNS find nearby Windows and Android devices in under 50ms — no pairing codes to hunt for.

Secure pairing

A one-time 6-digit PIN or QR handshake keeps unrecognized devices off your transfer session on shared Wi-Fi.

Batch & deep folders

Send single files, multi-gigabyte archives, or nested directory trees with SHA-256 / CRC32 integrity checks built in.

Glass desktop UI

A lightweight React + Tauri interface under 5MB, styled with a translucent, low-noise dark theme.

Native Android client

Material 3 design, dark mode, live speed gauges, and a background service so transfers survive app-switching.

Getting started

From download to first transfer

1

Download AeroSync.exe

Grab the latest release binary from the GitHub releases page.

2

Run the installer

Launch AeroSync.exe directly, or use Start_AeroSync_Desktop.bat.

3

Allow SmartScreen

If Defender SmartScreen prompts you, choose More Info → Run anyway.

4

Allow the firewall rule

Accept the Windows Firewall prompt on Private networks so peers can reach you.

1

Download AeroSync.apk

Grab the latest APK from the GitHub releases page.

2

Enable unknown sources

Allow installs from your browser or file manager when prompted.

3

Grant permissions

Approve Nearby Devices, Wi-Fi, and Storage/Media access.

4

Join the same network

Connect your phone and PC to the same Wi-Fi, or hotspot the PC off your phone.

5

Tap to pair

Your devices appear automatically in the radar view — tap one to start transferring.

Trust

Nothing leaves your network

No remote servers

Transfers stay fully peer-to-peer over your local network — no metadata, logs, or file contents touch a cloud server.

PIN-protected pairing

Unrecognized devices can't initiate a transfer without a one-time verification step.

Verified integrity

Every chunk is checked with rolling checksums, so what arrives is byte-for-byte what was sent.

Two devices. One local network. That's it.

No accounts, no cloud step, no size limits — install the client for your platform and start moving files.
